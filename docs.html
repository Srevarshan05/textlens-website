What is TextLens?

TextLens is a local, VLM-powered OCR framework for Python. It turns images and PDFs into useful text while keeping model selection, CUDA checks, batch processing, and local serving in one reusable developer workflow.

Local by design.

Your files stay on your computer. Most supported engines are vision-language models, so an NVIDIA CUDA GPU is strongly recommended.

The problem we addressed

Developers repeatedly rebuild the same OCR setup: choose a model, load images, render PDFs, check GPU VRAM, manage folders, handle retries, export results, and expose an API. TextLens makes those pieces reusable through a clear Python API.

  • One input layer for images, PDFs, URLs, bytes, and Pillow images.
  • One catalog with model, parameter, and VRAM guidance.
  • One BatchOCR workflow for folder-scale processing.
  • One local REST API with Swagger documentation.

Install

python -m venv .venv
.venv\Scripts\activate
python -m pip install "textlens-srevarshan[inference,ui]"

Use textlens-srevarshan[catalog] for live model discovery, and add server for the REST API.

OCR an image or PDF

from textlens import OCR

ocr = OCR(model="glm-ocr")
text = ocr.read("invoice.png")
print(text)

BatchOCR

BatchOCR scans a folder for PDFs and supported images, retries failures, writes one export per document, and produces a batch manifest.

from textlens.batch import BatchOCR

batch = BatchOCR(model="glm-ocr", workers=1, output_dir="./results")
results = batch.run("./documents")

Start with workers=1 on a single GPU; each worker can consume model VRAM.

TextLens Doctor

Run textlens doctor before downloading a model. It checks CUDA, GPU model, VRAM, PyTorch, CPU, RAM, and recommends which TextLens model can run on your machine.

$ textlens doctor
GPU NVIDIA GeForce RTX 4050 Laptop GPU
VRAM ✓ 6.0 GB
CUDA ✓ Available
Model ✓ glm-ocr compatible

Serve OCR locally

import textlens

textlens.serve(host="127.0.0.1", port=8000)

Open http://127.0.0.1:8000/docs for Swagger UI.

NVIDIA CUDA setup

Install an NVIDIA graphics driver, confirm it with nvidia-smi, then install the current CUDA-enabled PyTorch wheel recommended by the official PyTorch installer. The full CUDA Toolkit is usually not required for TextLens. Run textlens doctor afterwards to verify the setup.
