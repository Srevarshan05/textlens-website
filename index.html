FAQ

Questions answered

Is TextLens cloud-based?+

No TextLens is designed for local OCR Images and PDFs are processed on your machine by the model you configure

Do I need an NVIDIA GPU?+

Most supported engines are VLMs so an NVIDIA CUDA GPU is strongly recommended CPU fallback exists but is substantially slower for larger files and batches

What does TextLens Doctor check?+

Doctor detects your GPU CUDA availability VRAM PyTorch setup CPU RAM and recommends a supported model tier

Can I run a local REST API?+

Yes Install the server extra and call textlens.serve() then use the Swagger page at http://127.0.0.1:8000/docs
